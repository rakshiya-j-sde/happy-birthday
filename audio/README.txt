=====================================================
TAMIL BIRTHDAY SONG / BACKGROUND MUSIC INSTRUCTIONS
=====================================================

To add your Tamil birthday song:
1. Copy your audio file into this folder.
2. Rename it to: birthday-song.mp3
   (Path: audio/birthday-song.mp3 or assets/birthday-song.mp3)

The website will automatically play this song when:
- You click "Open Your Birthday Surprise 💜" (after the 3-2-1 countdown!)
- You click the "🎵 Melody" button in the top navigation bar.

If this file is not added yet, the website automatically plays a
delightful harmonic celebration melody so it never breaks!
